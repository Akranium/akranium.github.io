# akranium.github.io

A personal portfolio website built with HTML, CSS, and JavaScript, hosted using **GitHub Pages**.

The website is where I showcase my skills, interests, and projects. It has a simple homepage and separate pages for different areas of interest.

## Live Website

[Visit My Portfolio](https://akranium.github.io/)

## Technologies

The website is built using:

- **HTML** – Page structure and content.
- **CSS** – Styling, layout, and responsive design.
- **JavaScript** – Additional website functionality.
- **GitHub Pages** – Website hosting.

## Website Structure

### Homepage

The homepage has an introduction, links to individual skill pages and a contact section.

### Skill Pages

Skills have its own dedicated page containing:

- A short introduction.
- About This Interest section, where I talk about how I met this skill and tools I use.
- A collection of related projects, showed as project cards.

Currently, the website includes pages for:

- Programming
- Translation

## Design

The website uses a minimal visual style with a white, yellow, and black color palette.
